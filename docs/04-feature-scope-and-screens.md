# 04 · 기능 범위 · 화면 구성 · 컨트롤 매핑

> **목적**: [03 경쟁 조사](03-competitive-landscape.md)에서 뽑은 기준선을 **기능 목록(FR)** 으로 확정하고,
> 그 기능을 **어느 화면이 어떻게 제공하는지**까지 잇는다. 화면·컨트롤 설계의 SSOT.
> **기반 구조 = `nexa-beep`**(크레이트 경계 · 자체 CPU 래스터라이저 · `plat` 포트) ·
> **컨트롤 계약 = `nexa-dir2` `ctl` + `nexa-beep` `nbeep-ctl`** 계승.
>
> **작성 2026-08-25.** 우선순위 범례: **P0 = 1차 필수**(이게 없으면 제품이 아니다) ·
> **P1 = 채택**(경쟁 우위) · **P2 = 후순위** · **✂ = 범위 밖**(하지 않기로 한 것).

---

## 0. 제품 한 줄과 설계 축

> **Nexa Clip** = *복사한 모든 것을, 세 OS에서 똑같은 화면으로, 암호화해 보관하고 한 번에 꺼내 쓰는 상주 도구.*

| 축 | 결정 | 출처 |
|---|---|---|
| **① 렌더** | 자체 CPU 래스터라이저 — Qt·WebView·Electron 금지. **3-OS 동일 화면** | [03 §6-2 ①](03-competitive-landscape.md#6-2-nexa-clip의-자리--세-개의-차별점) |
| **② 동작** | 시각은 한 벌, **동작 관례는 각 OS 네이티브**(수식 키·스크롤·컨텍스트 메뉴) | `nexa-beep` `docs/14 §1` |
| **③ 보안** | 기록은 **기본 암호화** · 민감 표식은 **캡처 자체를 안 한다** | [03 §6-2 ②](03-competitive-landscape.md#6-2-nexa-clip의-자리--세-개의-차별점) |
| **④ 무게** | 24시간 상주 — **유휴 RSS·바이너리 크기에 CI 게이트** | `nexa-dir2` DR-2 |
| **⑤ 경계** | OS 의존은 `plat` 하나에 격리. 나머지는 3타깃 공통 | `nexa-beep` `docs/01 §1` |

### 1-1. 캡처 (FR-C) — 클립보드에서 우리 쪽으로

| ID | 기능 | 우선 | 비고 · OS 차이 |
|---|---|:--:|---|
| **FR-C-1** | **클립보드 변경 감시**(상주) | **P0** | Win = `WM_CLIPBOARDUPDATE` 이벤트 · mac = `changeCount` **폴링**(주기 설정) · X11 = `XFIXES` · Wayland = `wlr/ext-data-control`. **미지원 컴포지터는 정직하게 "수집 불가"로 표시**(조용한 실패 금지) |

| **FR-C-4** | **파일·폴더 경로** 캡처 | **P0** | Win = `CF_HDROP` · mac = `NSFilenamesPboardType`/file URL · Linux = `text/uri-list`. **Win+V가 못 하는 것** |
| **FR-C-5** | **HTML / RTF 서식** 보존(+ 평문 동시 보관) | ★ **P0** | Word·PPT 요구로 승격(08-25) → [12](12-clipboard-formats.md) |

| **FR-C-7** | **출처 기록** — 복사한 앱 이름·아이콘·시각 | **P1** | 검색/필터 축이 하나 늘어난다("VS Code에서 복사한 것") |

| **FR-C-10** | 중복 감지 — 같은 내용 재복사 시 **새 항목 대신 최신으로 승격** | **P0** | 목록이 같은 것으로 도배되는 걸 막는다 |
| **FR-C-11** | 캡처 일시 정지 / 재개 | **P1** | 민감 작업 중 수동 차단 |
| **FR-C-12** | 이미지 디코드 **격리 프로세스** | **P1** | `nexa-beep` `imgdec` 계승 — 파서 취약점이 본체를 못 건드린다 |

| **VT-3** | ★ **항목 액션은 선택이 없으면 비활성** — 상태가 보인다 |
| **VT-4** | 세로 공간이 모자라면 **스크롤 대신 하단 구역(⏸⚙)을 바닥에 고정**하고 중간만 접는다 |
| **VT-5** | 우클릭 컨텍스트 메뉴가 **같은 항목을 전부 제공**한다 — 툴바는 지름길이지 유일 경로가 아니다 |

**★ 사이드 패널(그룹·스니펫)은 기본 접힘** — VS Code 액티비티 바와 같은 모델이다. 펼치면 목록 왼쪽에 붙고, `▦`로 다시 접는다. **접힌 상태가 기본값**이라 처음 여는 사용자는 **목록만 본다.**

**④ 상태 바(옵션)** — `ui.show_footer`로 끌 수 있다([14 §3-7](14-settings-registry.md#3-7-모양-appearance) · Maccy 선례). 켜져 있어도 **선택 액션은 넣지 않는다**(좌측 툴바·컨텍스트 메뉴가 담당) — 순수 상태 표시(개수·암호화·모드)만.

#### 2-2-3. ★ ③ 목록 — 세 가지 보기 모드

> 사용자 확정: *"일반 보기에서는 이미지·리치텍스트 등 그대로, 간략 보기에서는 1줄씩 보여주면서 이미지나 리치텍스트는 간략하게 전체표시, 한 줄 보기에서는 Plain Text로 1줄만."*

**▤ 일반 보기 (Rich)** — 행 높이 **가변**. 내용을 **있는 그대로 렌더**한다.

```
┌──────────────────────────────────────────────────────────┐
│ 📄 2026년 계약서 초안                  Word · 2분 전  📌 │
│   ┌────────────────────────────────────────────────────┐ │
│   │  이름      나이                                     │ │ ← 리치텍스트 서식 그대로
│   │  배상용    49                                       │ │
│   └────────────────────────────────────────────────────┘ │
│   [서식] [평문] [표]                        ← 보유 표현  │
├──────────────────────────────────────────────────────────┤
│ 🖼 스크린샷                          Chrome · 10분 전    │
│   ┌──────────────────┐                                   │
│   │   (썸네일 크게)   │  1920×1080 · 482KB               │
│   └──────────────────┘                                   │
└──────────────────────────────────────────────────────────┘
```

**▥ 간략 보기 (Compact · 기본값)** — 행 높이 **고정 1행**. 이미지·리치텍스트는 **작은 썸네일로 전체를 축소 표시**.

```
│ 📄 2026년 계약서 초안 — 이름 나이 배상용 49  [▦] Word · 2분 전   📌 │
│ 🖼 스크린샷 1920×1080                        [🖼] Chrome · 10분 전   │
│ 📁 3개 파일 — 보고서.xlsx 외 2               [📁] 탐색기 · 1시간 전  │
│ 🎨 #2D6A4F                                   [■] Figma · 2시간 전   │
```

**▬ 한 줄 보기 (Plain)** — **Plain Text 1줄만**. 최대 밀도 · 최고 속도.

```
│ 이름  나이  배상용  49                                      2분 전 │
│ [이미지 1920×1080]                                         10분 전 │
│ D:\작업\보고서.xlsx; D:\작업\초안.md; D:\작업\사양서.pdf     1시간 전 │
│ #2D6A4F                                                    2시간 전 │
```

| 모드 | 행 높이 | 이미지 | 리치텍스트 | 용도 |
|---|---|---|---|---|
| **▤ 일반** | 가변 | 큰 썸네일 | ★ **서식 렌더** | 내용을 확인하며 고를 때 |
| **▥ 간략** | 고정 1행 | 작은 썸네일(전체 축소) | 작은 미리보기 + 평문 요약 | ★ **기본값** — 균형 |
| **▬ 한 줄** | 고정 1행 | `[이미지 W×H]` 텍스트 | **평문 1줄** | 많은 항목을 빠르게 훑을 때 |

| 규칙 | 내용 |
|---|---|
| **V-1** | ★ **세 모드 모두 가상화**한다 — 일반 보기는 행 높이가 가변이라 **높이 캐시**가 필요(FR-U-10) |
| **V-2** | 모드는 **기억된다**(창별이 아니라 앱 설정) · `Ctrl+1·2·3`으로 즉시 전환 |
| **V-3** | 어느 모드에서도 **선택·키 조작은 동일** — 모드는 **렌더만** 바꾼다 |
| **V-4** | 일반 보기의 리치텍스트 렌더는 **무해화 후**(RLO·제어문자 — FR-S-10) · **스크립트·외부 리소스 로드 없음** |
| **V-5** | 한 줄 보기의 평문은 **저장된 `text/plain` 표현**을 쓴다([12 §4 F-2](12-clipboard-formats.md#4-저장-모델--이름째로-전부-보관한다) — 폴백이 항상 있다) |

> ⚠️ **V-4가 보안 요구다.** *"리치텍스트를 그대로 보여준다"* 를 순진하게 구현하면 **HTML 렌더러가 공격면**이 된다.
> 우리는 브라우저 엔진이 없으므로(DR-1) **서식 일부(굵기·색·표·목록)만 그리는 제한 렌더러**를 쓴다 — 스크립트도 네트워크도 없다.

```
├── nclip-ui       화면          S1~S8 조립 — ★ **beep `settings.rs` 프레임워크 이식**(registry만 교체)

├── nclip-plat     플랫폼 경계   ★ 클립보드 감시·읽기/쓰기 · 전역 단축키 · 키 주입 ·
│                               직전 포커스 창 · 트레이 · 자동시작 · 창/입력/IME/DPI
├── nclip-imgdec   (bin)         이미지 격리 디코드                         ← beep 이식
└── nexa-conf      설정          설정 직렬화·영속                           ← beep에서 그대로 재사용
```

> **의존 방향은 단방향** — 어댑터가 `core`에 의존하고, `core`는 아무에게도 의존하지 않는다(의존성 역전).
> ★ **이 프로젝트의 난이도는 전부 `nclip-plat`에 모인다**([§1-1 FR-C-1](#1-1-캡처-fr-c--클립보드에서-우리-쪽으로) · [§2-1 경고](#2-1-s1--퀵-팝업--주-화면)). 나머지는 3타깃 공통 코드다.

## 5. 열려 있는 결정 (ADR 후보)

| # | 결정할 것 | 선택지 |
|---|---|---|
| **D-1** | 저장 형식 | 자체 세그먼트 파일(beep `store` 계승) vs SQLite(외부 crate — DR "외부 crate 0 지향"과 충돌) |
| **D-2** | 검색 방식 | 선형 스캔(복호 후) vs 블라인드 인덱스 vs 평문 인덱스(보안 후퇴 — 기각 예상) |
| **D-3** | macOS 폴링 주기 | 고정 vs 적응형(포커스 변화·유휴 감지) |
| **D-4** | Wayland 미지원 환경 | 기능 축소 실행 vs 실행 거부 + 안내(온보딩 4단계) |
| **D-5** | 자동 붙여넣기 구현 | 키 주입 vs 클립보드 교체 후 사용자 `Ctrl+V` 안내(권한 없는 환경 폴백) |
| **D-6** | P2P 동기화 시점 | 1차 제외 확정 vs `nexa-beep` 자산 조기 결합 |
