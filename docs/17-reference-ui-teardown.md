# 17 · 참조 제품 UI 해부 — Maccy 팝업 · CopyQ 메인창/트레이

> **근거**: 사용자가 제공한 실물 캡처 — **Maccy 팝업 2장**(2026-08-26) · **CopyQ 메인창 + 트레이 우클릭 2장**(2026-08-26).
> **목적**: [DR-12](10-decision-record.md)(화면 구성)를 **실사용 제품의 실물**로 검증하고 다듬는다.
> ★ 사용자가 **매일 쓰는 두 제품**이므로, 여기서 발견한 것은 취향이 아니라 **검증된 패턴**이다.
>
> 설정 항목은 [14](14-settings-registry.md), 화면 설계 본문은 [04 §2](04-feature-scope-and-screens.md).

## 1. Maccy 팝업 (macOS)

```
┌──────────────────────────────────────────────┐
│ Maccy  🔍 type to search…            [▤]    │  ← 타이틀 + 검색 + 패널 토글
├──────────────────────────────────────────────┤
│ ▣(썸네일)                            ⌘1     │  ← 이미지는 인라인 썸네일
│ ▣(썸네일)                            ⌘2     │
│ CREATE INDEX BISCM.IX_M4…ITEMOP');↵  ⌘8     │  ← ↵ 로 개행 표시 · 가운데 생략
│ 내용 정리 후 진행사항 최신화…push 해줘  ⌘9     │
│ nexa-beep 클립보드 "왕복" 시험                │
│ https://github.com/SosomLab                  │
├──────────────────────────────────────────────┤
│ Clear          ⌥⌘⌫                          │  ← 고정 푸터
│ Preferences…   ⌘,                            │
│ About                                        │
│ Quit           ⌘Q                            │
└──────────────────────────────────────────────┘
```

| # | 관찰 | 판단 |
|:--:|---|---|
| **M-1** | ★ **번호 단축키가 `⌘1`~`⌘9`** (맨숫자 아님) | ★★ **우리 초판 설계가 틀렸다** — 검색 필드가 항상 포커스라 맨숫자는 검색어가 된다 → [§5](#5-이-해부로-정정된-것) |
| **M-2** | ★ **개행을 `↵` 로 표시** | ★ 채택 — 한 줄 요약에서 **구조가 보인다** |
| **M-3** | ★ **긴 텍스트는 가운데 생략**(앞·뒤 남김) | ★ 채택 — 끝을 자르면 식별이 어렵다 |
| **M-4** | 이미지는 **행 안 인라인 썸네일**(높이 설정) | ★ 채택 |
| **M-5** | ★ **고정 푸터**에 비우기·설정·정보·종료 | ★ 채택 — 팝업 자체가 메뉴 역할까지 한다 |
| **M-6** | 미리보기는 **우상단 토글 버튼** | ★ 채택 — 초판의 "폭 좁으면 자동 숨김"보다 낫다 |
| **M-7** | 팝업이 **메뉴바 드롭다운**으로 붙어서 열림 | △ 우리는 `ui.popup_at`(커서/중앙/마지막)로 **선택 가능**하게 |
| **M-8** | 상단 1줄에 **타이틀 + 검색**을 함께 | ★ 채택 — 세로 공간 절약 |

## 2. CopyQ 메인창 (Windows)

```
┌───────────────────────────────────────────────────────┬───┐
│ <IMAGE> - CopyQ                              ─ □ ✕   │   │ ← ★ 제목에 현재 클립보드
├───────────────────────────────────────────────────────┤ 📄│
│ File   Edit   Item   Tabs   Help                      │ 📌│ ← ★ 우측 세로 툴바
├───────────────────────────────────────────────────────┤ 🏷│
│ 26  ┌───────────────────────────────────┐             │ 🏷│
│     │ (문서/표 이미지를 큰 썸네일로 렌더) │             │ 🏷│
│     └───────────────────────────────────┘             │ 📋│
│ 27  SosomLab — 소프트웨어 개발·아키텍처   ← 링크 렌더   │ ℹ │
│ 28  M4S_I003081                                       │ 🗑│
│ 29  M4S_I003080                                       │ ✏│
│ 30  START_YYMMDD                                      │ ⚡│
└───────────────────────────────────────────────────────┴───┘
   ↑ 행 번호
```

| # | 관찰 | 판단 |
|:--:|---|---|
| **C-1** | ★ **메뉴바 = File / Edit / **Item** / **Tabs** / Help** | ★ **`Item` 메뉴 채택** — 항목 액션을 한곳에 모으는 자리가 실제로 필요하다. `Tabs`는 우리 **그룹/보드**에 대응 |
| **C-2** | ★ **우측 세로 툴바**(항목 액션: 고정·태그·복사·정보·삭제·편집·액션) | ★ **채택 검토** — 상단 가로 툴바보다 **목록 폭을 덜 먹고**, 항목 컨텍스트 액션에 가깝다 → [D-42](#6-열린-결정) |
| **C-3** | ★ **행 번호(26·27·28…)** 좌측 표시 | ★ 채택(옵션) — 위치 감각 + 번호 단축키와 시각적으로 연결된다 |
| **C-4** | ★ **일반 보기에서 리치 콘텐츠를 실제로 렌더** — 표·색·이미지가 그대로, **링크는 파란 밑줄 링크로** | ★★ **우리 `RichTextView`(FR-U-16) 요구와 정확히 일치** — 다만 우리는 **제한 렌더러**(스크립트·네트워크 0) |
| **C-5** | **행 높이가 내용에 따라 가변**(이미지 크게 / 텍스트 1줄) | ★ 우리 **일반 보기** 정의와 동일 → **가변 행 높이 가상화**(V-1)가 필수임이 재확인 |
| **C-6** | ★ **제목 표시줄에 현재 클립보드 내용**(`<IMAGE> - CopyQ`) | △ 채택 검토 — "지금 클립보드에 뭐가 있나"를 늘 알려준다 |

## 3. CopyQ 트레이 우클릭 메뉴 (Windows)

```
┌────────────────────────────────────────────────┐
│ 검색할 형식                                     │ ← ★ 메뉴 안 검색 필드
├────────────────────────────────────────────────┤
│ ▣ 1. <IMAGE>                                   │
│ ▣ 2. <IMAGE>                                   │ ← 최근 5개 + 미니 썸네일
│ ▣ 3. <IMAGE>                                   │
│ ▣ 4. <IMAGE>                                   │
│ ▣ 5. <IMAGE>                                   │
├────────────────────────────────────────────────┤
│ 📋 Clipboard: <IMAGE>                          │ ← ★ 현재 클립보드
│ 📄 마우스 커서 아래 메인 윈도우 보이기            │
│ 📋 클립보드를 일반 문자로 붙여넣기                │ ← ★ 평문 붙여넣기가 1급 항목
├────────────────────────────────────────────────┤
│ Show/Hide                                      │
│ 🔧 Preferences…                        Ctrl+P  │
│ Disable Clipboard Storing        Ctrl+Shift+X  │ ← 캡처 일시정지
│ ⏻ Exit                                 Ctrl+Q  │
└────────────────────────────────────────────────┘
```

| # | 관찰 | 판단 |
|:--:|---|---|
| **T-1** | ★ **트레이 메뉴 안에 검색 필드** | ★ **채택 검토** — 최근 N개를 넘어서는 항목도 메뉴를 떠나지 않고 찾는다 → [D-43](#6-열린-결정). ⚠️ 네이티브 메뉴에 입력 필드를 넣는 건 OS마다 제약이 다르다 |
| **T-2** | ★ **`Clipboard: <내용>` — 현재 클립보드를 별도 항목으로** | ★★ **채택** — 우리에게 없던 아이디어. *"지금 뭐가 담겨 있나"* 는 클립보드 도구의 근본 질문이다 |
| **T-3** | ★ **"클립보드를 일반 문자로 붙여넣기"가 메뉴 1급 항목** | ★★ **채택** — [DR-11](10-decision-record.md)(평문 붙여넣기)이 얼마나 자주 쓰이는지 보여준다. 단축키를 모르는 사용자의 경로 |
| **T-4** | **"마우스 커서 아래 메인 윈도우 보이기"** | ★ 우리 `ui.popup_at = 커서`와 같은 것([14 §3-7](14-settings-registry.md#3-7-모양-appearance)) |
| **T-5** | **`Disable Clipboard Storing` + 단축키 노출** | ★ 채택 — 우리 `cap.enabled` 토글에 **단축키를 붙인다** |
| **T-6** | 최근 항목이 **5개**(Maccy는 메뉴 아님) | 우리 기본 **8개**(5~10 설정) 유지 — [TR-1](04-feature-scope-and-screens.md#2-4-s6--트레이-메뉴--s7--온보딩) |
| **T-7** | 각 항목에 **미니 썸네일** | ⚠️ **OS 네이티브 메뉴에 비트맵을 넣는 것은 플랫폼별 제약**이 있다 → 1차는 **타입 아이콘 + 텍스트**([TR-2](04-feature-scope-and-screens.md#2-4-s6--트레이-메뉴--s7--온보딩)), 여유되면 승격 |

## 4. 두 제품의 차이가 우리에게 알려주는 것

| 축 | **Maccy** | **CopyQ** | 우리 |
|---|---|---|---|
| **주 진입점** | 팝업 하나(메뉴바 드롭다운) | 메인창 + 트레이 메뉴 | ★ **셋 다**([04 §2-4](04-feature-scope-and-screens.md#2-4-s6--트레이-메뉴--s7--온보딩)) — 키보드/마우스/탐색 사용자 |
| **목록 렌더** | 1줄 요약 + 인라인 썸네일 | ★ **리치 콘텐츠 그대로**(가변 높이) | ★ **보기 3모드**로 둘 다 제공 |
| **항목 액션 위치** | 단축키·메뉴 | ★ **우측 세로 툴바** | D-42 |
| **평문 붙여넣기** | 설정 + 수식 키 | ★ **트레이 메뉴 1급 항목** | ★ **둘 다** |
| **현재 클립보드 표시** | ✕ | ★ **제목 + 메뉴 항목** | ★ 채택(T-2) |
| **철학** | 최소 · 빠름 | 전부 가능 · 학습곡선 | 기본은 Maccy, 깊이는 CopyQ — **깊이를 팝업에 쏟지 않는다** |

## 5. 이 해부로 **정정된 것**

| # | 무엇 | 초판 | 정정 |
|:--:|---|---|---|
| **1** | ★ **번호 단축키** | `1`~`9` 맨숫자 | **`Ctrl+1`~`9` / `⌘1`~`⌘9`** — 검색 필드 포커스 때문에 맨숫자는 **동작하지 않는다**(M-1) |
| **2** | 팝업 필터 바 | 한 줄 상시 점유 | 헤더 흡수 / 스크롤 영역 안 칩 — **세로 공간은 목록에** |
| **3** | 미리보기 패널 | 폭 좁으면 자동 숨김 | **명시적 토글**(M-6) |
| **4** | Maccy 파일 캡처 | *"미확인"* → 이후 *"없음"* 으로 서술 | ★ **있다**(Storage 탭 `Save: Files`) — [03 §5-4-2 U-4](03-competitive-landscape.md#5-4-2-실사용에서-나오는-요구--두-앱을-오갈-때-실제로-겪는-것)에서 정정 완료 |

## 6. 열린 결정

| # | 결정할 것 | 선택지 | 권장 |
|---|---|---|---|
| **D-42** | 메인창 항목 액션 배치 | 상단 가로 툴바 · ★ **우측 세로 툴바**(CopyQ) · 둘 다 | ★ **상단=전역/보기, 우측 세로=항목 액션** 분리 |
