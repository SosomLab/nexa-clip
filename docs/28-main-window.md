## 1. 자리매김 — 세 화면의 분업

| 화면 | 역할 | 여는 길 |
|---|---|---|
| S1 퀵 팝업 | **골라 붙이기**(1.5초 왕복 · 주입) | 전역 단축키 |
| ★ **S2 메인창** | **항목 관리** — 핀·삭제·검색·(후속: 편집·태그·정렬) | **트레이 좌클릭 · "열기"** |
| S3 설정 | 정책·보안·모양 | ★ **메인창 툴바 ⚙**(승격 해제 — 08-30 확정) |

## 2. 1단 범위 (이번 구현)

[04 §2-2]의 확정 레이아웃을 계승하되 **크롬 최소 판**으로 시작한다:

```
┌──────────────────────────────────────────────┐
│ 🔍[ 검색…                                 ]  │ ① 검색 1줄(메뉴바는 후속)
├───┬──────────────────────────────────────────┤
│ 📌│ ▣  스크린샷 1920×1080         Chrome  2 │
│ 🗑│ 📄 CREATE INDEX …             DBeaver   │ ③ 목록(세로 최대 ·
│ ─ │ 📌 고정된 항목                 Word     │    핀은 위로 정렬)
│ 📋│ …                                        │
│ 📄│                                          │
│ ─ │                                          │
│ ⚙│                                          │
├───┴──────────────────────────────────────────┤
│ 14개 · 🔒 암호화 · 로컬                       │ ④ 상태 1줄
└──────────────────────────────────────────────┘
  ↑② 세로 툴바 40px(VT-1~5 계승 · 아이콘은 벡터 — 글꼴 글리프 금지(09-01 − 두부 교훈))
```

| 포함(1단) | 후속(본편) |
|---|---|
| 검색(부분 문자열) · 목록(썸네일·글리프·출처·copies) | 메뉴바 · 정규식/대소문자 토글 · 한글 조합 검색(T-17) |
| ★ **핀 토글**(핀 = 목록 상단 고정 표시 · 축출 면제 — T-16 배선 완료) | 태그 · 그룹 · 사이드 패널 |
| ★ **삭제**(Delete · 저장소 동기) | 항목 **편집**(S4 시트) · 대량 선택 |
| **복사**(Enter/더블클릭 = 원본 재적재 · ⇧ = 평문) — 주입 없음(관리 화면) | 보기 3모드 · 가변 행 가상화(T-18b 본편) |
| ⚙ = 설정 창 · 상태줄(개수·암호화) | 행 번호 · 정렬 옵션 · 내보내기 |

## 3. 동작 계약

| 입력 | 동작 |
|---|---|
| 타이핑 / Backspace | 검색 필터(라벨 부분 일치 · 소문자 접기) |
| ↑↓ · 휠 | 선택 이동 · 스크롤 |
| Enter / 더블클릭 | **원본 재적재**(전 표현) — 다른 앱에서 Ctrl+V |
| ⇧Enter | 평문만 재적재 |
| Delete / 🗑 | 선택 삭제 — 이력 + 저장소(REMOVE 이벤트) |
| Ctrl+P / 📌 | 핀 토글 — 저장소는 같은 id Add 재기록(= 교체 재생) |
| Esc / X | 창 숨김(`ui.close_to_tray` 정책 공유 · 상주 유지) |
| ⚙ | 설정 창 열기 |

| 규칙 | 근거 |
|---|---|
| **핀 항목은 목록 상단 구획**(최신순 유지 · 구분선) | 관리 화면의 존재 이유 — 자주 쓰는 것이 안 떠내려간다 |
| 항목 액션은 **선택 없으면 비활성**(VT-3) | 상태가 보인다 |
| 삭제 실행 취소는 **없다**(1단) — 후속 검토 | 팝업이 아니라 관리 화면: 실수 여지가 작고, 되돌리기는 저장소 이벤트로 자연 확장 가능 |

## 4. 저장 연동 (T-16)

| 조작 | 이력 | 저장소 |
|---|---|---|
| 핀 토글 | `History::set_pinned` | `add(같은 id)` — 재생 시 교체 = 핀 영속 |
| 삭제 | `History::remove(id)`(신설) | `remove(id)` |
| 복사(재적재) | `expect_echo` — 에코 = 승격 | `touch`(에코 push 경로 그대로) |
