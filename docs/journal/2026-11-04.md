## 2차 — GAP-042 우회 이식: winit 0.30.13 `TaskbarCreated` 교착 (개발 · nexa-dir3 `cd17f2d` 이식)

- **증상**: RDP 재접속 · explorer 재시작 때 셸이 `TaskbarCreated`를 브로드캐스트 → winit 0.30.13이 창 상태 Mutex를 쥔 채 `ITaskbarList::AddTab`(`SendMessageW` 동기 대기) → 테마 후처리 `WM_WINDOWPOSCHANGING` 재진입 → 창이 **영구 "응답 없음"**. nexa-dir 설치본 0.29.0 미니덤프로 원인 확정 · 상류 수정 PR #4563은 winit 0.31에만 있음.
- **우회**: 창 생성 직후 서브클래스를 걸어 `TaskbarCreated` 하나만 `DefWindowProcW`로 돌려 winit 처리를 건너뛴다. 앱은 `skip_taskbar`를 쓰지 않으므로 동작 차이 0.
