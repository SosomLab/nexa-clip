### ① 지시 · 실측

- 사용자: *"팝업 단축키를 계속 누르고 있어도 떼기 전에는 1회만 팝업으로 동작하도록 제약"* + *"팝업 뜬 상태에서 다시 단축키 누르면 토글로 사라지는 기능은 유지"*.
- 실측(개발 세션 · `dbus-monitor` · 하네스로 단축키 1.8초 유지): mutter가 포털 `GlobalShortcuts.Activated`를 **첫 신호 뒤 500ms(키 반복 지연)에 둘째, 이후 약 30ms 간격으로 계속**(70여 건) 보내고 **`Deactivated`는 0건** → 앱이 신호마다 열기/닫기(토글) 반복.

### ② 수정(개발 세션 · `hotkey_linux.rs`)

- `RepeatFilter`(포털 시각 기준): 직전 신호 뒤 **[키 반복 지연 + 120ms] 안**이면 반복 시작 → 버림 · 반복 중에는 **200ms 안에 이어지는 한** 버림 · 그보다 뜸을 두면 **새 누름**으로 받음(= 토글 유지).
- `key_repeat_delay_ms` — `gsettings org.gnome.desktop.peripherals.keyboard delay`(못 읽으면 500) · 테스트 1.
- Windows = `MOD_NOREPEAT` · mac = Carbon 1회라 무변경.
- ⚠️ 알려진 한계: 띄운 뒤 **약 0.6초 안의 아주 빠른 두 번 누름은 한 번**으로 침.
