목록엔 수신 표시 점, 미리보기/우클릭에 출처 · 그리고 **중복 제외 보기** 스위치(로컬 1건 우선 · 수신끼리는 최근 1건).

| 축 | 내용 |
|---|---|
| 이력 동일성 | ★ **합성 표현 무시**(`CF_TEXT`·`CF_OEMTEXT`·`CF_LOCALE`·`CF_DIBV5`·`CF_BITMAP`·`CF_METAFILEPICT`) — 지문·동일성·부분집합 모두. 원격에서 받아 게시한 `CF_UNICODETEXT` 하나와 감시가 다시 읽은 "+합성 3종"이 같은 내용으로 판정된다(종전엔 어긋나 에코가 새 로컬 항목을 만들었다) |
| 기기별 항목 | 승격 판정에 `remote_origin`(출처 `⇄ ` 접두) 일치 조건 — 같은 내용이라도 **로컬 / mac 수신 / linux 수신은 별도 행**, 같은 기기 재수신은 그 행 승격(×N). 테스트 `remote_items_separate_per_sender` |
| 표시 | 목록: 수신 항목 앞 **녹색 점**(상태줄 연결 점과 같은 색 · 핀 점 옆/아래) · 미리보기: 첫 줄 "출처 ⇄ 기기명" · 우클릭: 맨 위 비활성 항목 "출처 ⇄ 기기명" · 상세 보기는 종전 우측 출처 텍스트 |
| ★ 중복 제외 보기 | 검색줄 오른쪽 **스위치**(`ui.dedup_view` 영속 · 라벨 "중복 제외") — 내용 열쇠(`History::content_key` = 합성 제외 지문)가 같은 행들 중 **로컬 1건**(가장 최근), 로컬이 없으면 **가장 최근 수신 1건**만. 순서는 최신순 유지. 셸이 `MainAction::DedupView` → 영속 + refresh |

**실측**: clippy 0 · 테스트 474(+1) · 두 인스턴스 재기동. ⏳ 실기: 같은 내용 동시 복사 → 로컬 1 + 수신 1(녹색 점) · 재복사 시 ×N ·
미리보기 첫 줄 출처 · 우클릭 출처 · 중복 제외 켜면 로컬 1건만.

## 9차(Windows) — ★ 재시도 정책 통일 · 릴레이 None · 기기별 승인 + 대조 코드 · 동기화 끔 = 전부 끔/잠금 (사용자 지시 4건)

**재시도 정책(사용자: "실패 횟수에 비례해 지수적으로 · 기준을 정리해 설명/옵션으로")** — `sync_cmd::Backoff{base,cap}`:

| 규칙 | 값 |
|---|---|
| 실패 n회째 대기 | `base × 2^(n−1)`, 상한 `cap`, **±20% 지터**(여러 기기 동시 몰림 방지), 성공하면 0으로 |
| 적용 | 릴레이 재접속(끊김도 1회 실패로 셈) · 알려진 기기 재다이얼(기기별) · 페어링 탐색 · LAN 다이얼(기기별) — **한 정책** |
| 설정 `sync.retry` | 표준 5s→5분(기본) · 느긋 15s→15분 · 적극 2s→1분 — 설명에 규칙 전문 · 실패 노트에 "N초 뒤 재시도(실패 k회)" |

종전 릴레이 고정표 [5,15,60,300]s는 폐기(같은 값이 표준 정책의 1·2·4·7회째에 해당). 테스트 `backoff_tests`.

**릴레이 `None`**(사용자 실기 절차 질문에 대한 답 겸): Relay server 옵션 **None = 같은 네트워크만**(러너 없이 LAN 직결 · 상태 `LanOnly` 노트) ·
서버 선택 = LAN + 릴레이. Test는 None이면 서버 시험 없이 LAN 전용으로 켠다. ⇒ "두 인스턴스 Disconnect 후 재시작"으로는
릴레이가 다시 붙어 LAN 검증이 안 된다 — **None으로 두고 Test**가 맞는 절차.

**기기별 승인**(사용자 찬성 → 착수): `SettingKind::DeviceList` 신설 — 행마다 [승인|해제][삭제](Safe/Default/Danger 톤) ·
온라인 행에 **6자리 대조 코드**(`sas::safety_number(me, peer)` 앞 6자리 — 키 쌍의 함수라 양쪽 동일 · docs/09 §6-3 "입력이 아니라 보기") ·
값 = `hex\tstate\ttext` · 클릭 = `sync.devices = approve:hex | revoke:hex | delete:hex` · 전체 승인 버튼 제거.

**동기화 사용 끔 = 동기화 자체 끔**(사용자): `stop_all()` — 릴레이·LAN·세션 전부, 상태 Off(노트 없음). **꺼져 있으면 아래 설정 9키 잠금**
(기기 이름·핸들·암호·서버·포트·재시도·Test·Disconnect·기기 목록 — 비밀 행 눈/생성 버튼도 잠금 존중). 잠금은 매 폴마다 계산(상태 조기 반환 앞).

**실측**: clippy 0 · 테스트 473 · debug 빌드 · 두 인스턴스 LAN 세션 유지. ⏳ 실기: 기기 행 버튼(승인→해제→삭제) · 양쪽 대조 코드 일치 ·
None 선택 시 LAN만 · 동기화 끔 = 목록 오프라인 + 아래 설정 흐림 · 재시도 옵션 변경 후 실패 노트의 대기 시간.

## 7차(Windows) — ★ 같은 네트워크 직결(릴레이 불요 · T-25/T-26 1단) + "네트워크가 UI를 멈추지 않게" (사용자 요청 2건)

| 축 | 내용 |
|---|---|
| 발견 | `lan.rs` — UDP 비콘 `47301`(5초): `NCLB` ‖ ver ‖ **LAN 태그 16B** ‖ PeerId hex ‖ TCP 포트. 태그 = `sha256("nclip-lan-v1" ‖ 페어링 RID)`(`rid::lan_tags` · 어제·오늘·내일 수용 · **RID 자체는 싣지 않는다** — LAN 도청자가 릴레이 만남 지점을 못 얻게). 송신 = 255.255.255.255 + **기본 경로 /24 지향 브로드캐스트**(가상 어댑터가 여럿이면 제한 브로드캐스트가 엉뚱한 곳으로만 나간다 — 이 PC 실측). 소켓 = 주소 재사용 + 브로드캐스트(`tcp::udp_beacon_socket` — 같은 PC 두 인스턴스가 함께 듣는다) |

| ★ UI 비차단(사용자) | 원칙: **UI 스레드는 채널 송수신·이력 등재·게시만**. 수신 = 세션 스레드가 디코드·OS 표현 변환(PNG→DIB)·에코 지문까지 끝내고 `SyncItem{reps,summary,skip_hash}` 전달 · 송신 = `has_peers()`(값싼 검사) 뒤 워커 스레드가 페이로드(DIB→PNG 인코드 포함) 생성·전송 · 릴레이/LAN/세션/다이얼은 전부 별도 스레드(타임아웃 · 세대 폴링) |

"세션 중복 — 새 것을 버림"(LAN이 먼저 서면 그쪽이 쓰인다). clippy 0 · 테스트 473(+2). 방화벽: 이 PC는 nexa-clip 인바운드
허용 규칙(Private)이 이미 있었다 — 다른 PC는 첫 실행 때 Windows 방화벽 허용이 필요할 수 있다(비콘 47301/udp · 수락 tcp).
⏳ 실기: **릴레이를 끊고**(서버 없이) 같은 LAN의 두 PC가 목록에 `(LAN)`으로 뜨고 전파되는지 · mac↔Windows LAN.

## 6차(Windows) — ★ `--profile <이름>`(한 PC에서 동기화 2대 시험) + "중계 서버 없이 가능한가" 답

**옵션**: `nexa-clip --profile b`(어느 명령 앞뒤든 · `--profile=b`도) → 데이터 폴더 `data/profiles/b`(설정·저장소·신원·
기기 목록·서버 핀 전부 분리 = **다른 기기**) · 단일 인스턴스 가드 = 뮤텍스/이벤트 이름에 프로필 접미(Unix는 잠금 파일이
폴더 안이라 저절로) · 창 제목 `[b]` · 트레이 툴팁 `Nexa Clip [b]` · 기본 기기 이름 `호스트명-b` · 자동 시작 등록은
프로필 실행이 건드리지 않음. 이름 규칙 영문·숫자·`-`·`_` 1~32자.
**실측**: 기본 + `--profile b` 동시 상주(PID 2개) · b는 0개 복원·별도 폴더 · 전역 단축키는 둘째가 등록 실패(첫째 소유 —
안내 메시지 · 트레이 좌클릭으로) — 시험엔 무해.

**사용자 질문 "같은 네트워크·같은 아이디·암호의 두 PC가 **중계 서버 없이** 동기화되는가"** — **아니오(현재 설계)**.
만남(페어링 RID 등록·Open)·종단 세션·항목 전파가 전부 릴레이(`beepd`) 경유다. `connect_via`의 UDP 홀펀칭도 릴레이가
관측 주소를 실어 줘야 시작된다. **LAN 직결은 T-25(LAN 발견)·T-26(직결)** — docs/09 §7 경로 A("내 기기 찾기") 설계만
있고 미구현. 필요한 것: LAN 비콘(mDNS 또는 UDP 브로드캐스트 · 핸들·암호 파생 RID로 응답 필터) → 직결 TCP(`tcp.rs` 링크 +
