## 1차 — 실기 후속 셋: "기록 사라짐"의 정체 · 팝업 클램프 · ★ 차단 목록 ListBox

전날 실기 잔여 통과(휠·트레이 최근·자동 시작·hover/스플리터 · Word 원본 서식 유지 설정 = 팝업도 정상).
보고 셋 처리:

### ① "Clear history on quit 꺼져 있는데 종료 시 기록이 사라짐" → **소실 아님 · 시작 블록**

진단 덤프 신설([`store_dump`](../../crates/nclip-store/examples/store_dump.rs) + `diag`) — 이벤트 로그 전수:
**REMOVE 0 · wipe 0 · 14항목 + blob 5 전부 생존** · 재적재 실측 "14개 복원". 실체는 **debug 빌드에서
ChaCha20이 opt-level 0(~10MB/s)** 이라 이미지 blob(17MB) 복원이 시작을 수 초 블록 — 그 사이 트레이
툴팁·팝업이 비어 "사라진 것으로" 보였다. 조치: dev 프로필에서 **암호 원어 크레이트만 opt-level 3**
(RustCrypto 관행 · release 무관). 후속 여지: blob 지연 적재(시작은 인덱스만) — T-16 본편.

### ② 팝업 화면 경계 클램프 (사용자 요청)

커서 좌상단 기준으로 그리면 우측 하단에서 잘렸다 → [`clamp_to_monitor`](../../crates/nexa-clip/src/popup_win.rs)
— 커서가 든 모니터를 찾아 **전체가 들어가게 좌상단을 되민다**(모니터 배율로 물리 크기 환산 ·
미검출 = 그대로 fail-soft).

### ③ ★ 차단 페이지·제외 앱 = ListBox + 추가/삭제 + 인라인 편집 (사용자 요청)

`;` 한 줄 자유 입력(RadioInput)이던 것을 **`ListEditor` 컨트롤 신설**(nclip-ctl 18번째)로 교체:

| 조작 | 동작 |
|---|---|
| 행 클릭 / 선택 행 재클릭 | 선택 / **인라인 편집**(더블클릭 사건이 없는 이벤트 모델) |
| ＋ / − / `Delete` | 빈 행 추가+즉시 편집 / 선택 삭제 |
| `Enter` / `Esc` | 확정(빈 값 = 행 삭제) / 취소(유령 줄 정리) |
| ↑↓ · 휠 | 선택 이동 · 5행 창 스크롤 |

값 모델은 `;` 구분 한 줄 그대로 — **저장 형식·게이트 판정 코드 무수정**(화면만 목록). 편집은
`TextBox` 재사용이라 IME·클립보드·우클릭 메뉴 라우팅이 콤보와 같은 문법(`editing_input`).
설정 위젯에 `SettingKind::ListEdit` 통합(높이·포커스 재계산·틱·편집 라우팅 5블록).
