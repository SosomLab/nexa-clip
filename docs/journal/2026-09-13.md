### ③ 받은 파일 저장 폴더 `sync.file_dir` (설정 → 동기화 · Text · 기본 빈 값)

| 축 | 구현 |
|---|---|
| 기본값 | ★ **OS 사용자 다운로드 폴더 아래 `Nexa Clip`** — Windows `%USERPROFILE%\Downloads` · mac `~/Downloads` · Linux **XDG**(`$XDG_DOWNLOAD_DIR` → `~/.config/user-dirs.dirs` 파싱 · 없으면 `~/Downloads`). 다운로드 폴더가 없으면 종전 위치 `<data>/cache/files` |
| 해석 | `xfer::resolve_file_dir(setting, data_dir)` — 값이 있으면 그대로(앞 `~` = 홈) · 비면 위 규칙. `nclip_plat::paths::downloads_dir`에 Linux XDG 추가 + OS 무관 파서 `parse_user_dirs_download`(테스트) |
| 적용 | 부팅 `xfer::init(dir, legacy)` · 설정 변경 즉시 `xfer::set_cache_dir` — **이후 전송부터** 새 폴더. 진행 중 `.part`는 제 경로를 들고 있어 무관 |
| ★ 연쇄 가드 유지 | `Manager.prev_dirs` — 바꾸기 전 폴더(와 부팅 시 실재하는 종전 `<data>/cache/files`)를 기억해 `is_cache_path`가 **계속 우리 캐시로 판정**한다. 폴더를 바꾼 뒤 옛 캐시 파일을 붙여넣어도 09-12의 2PC 핑퐁이 다시 열리지 않는다(테스트 `changing_dir_keeps_recognizing_old_dir`) |
| 이미 받은 파일 | 옮기지 않는다(캐시 메모만 비움 → 새 폴더에 없으면 다시 받는다). 설명문에 명시 |
| 구조 | 항목마다 `<폴더>/<열쇠 32hex>/<원본 이름>` — 같은 이름끼리 충돌하지 않는 대신 하위 폴더 이름이 열쇠다(사람이 읽는 이름은 그 안의 파일) |
