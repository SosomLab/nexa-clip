## 1. 화면 레이아웃 개괄

### 1-1. 화면 지도 — 진입점 3개

```
              ┌──────────────────────────────────────┐
 전역 단축키 →│ S1 퀵 팝업   키보드 사용자 · 3초      │→ 붙여넣기
              └──────────────────────────────────────┘
              ┌──────────────────────────────────────┐
 트레이 좌클릭→│ (같은 S1 팝업)                        │
 트레이 우클릭→│ S6 트레이 메뉴  최근 8개 · 마우스     │→ 붙여넣기
              └──────────────────────────────────────┘
              ┌──────────────────────────────────────┐
      메뉴/키 →│ S2 메인창   탐색·정리·대량 작업        │→ S3 설정 · S4 편집 · S5 스니펫
              └──────────────────────────────────────┘
```

| 화면 | 성격 | 우선 |
|---|---|:--:|
| **S1** 퀵 팝업 | ★ 가장 빠른 경로 | P0 |
| **S2** 메인창 | 메뉴 + **좌측 세로 툴바** + 목록 | P0 |
| **S3** 설정 | 좌측 카테고리 + 우측 폼(VS Code 방식) | P0 |
| **S4** 항목 편집 시트 | 내용 수정 후 붙여넣기 | P1 |
| **S5** 스니펫 편집 | 정형구 관리 | P1 |
| **S6** 트레이 메뉴 | 최근 N개 + 현재 클립보드 + 평문 붙여넣기 | P0 |
| **S7** 온보딩 | ★ 권한·환경 점검 | P0 |
| **S8** 정보 | 버전·라이선스·데이터 경로 | P0 |

## 3. ★ 각 기능의 구현 방법

> **표기**: `🆕` = 새로 만든다 · `♻` = [beep에서 이식](13-ui-reuse-from-beep.md) · `⚠` = 최대 난관

### 3-1. `⚠🆕` 클립보드 감시 (FR-C-1)

**beep에는 읽기/쓰기만 있고 감시가 없다.** 이 프로젝트에서 새로 만드는 가장 중요한 부분.

| OS | 방식 | 요점 |
|---|---|---|
| **Windows** | `AddClipboardFormatListener(hwnd)` → **`WM_CLIPBOARDUPDATE`** | **숨은 메시지 창**이 필요(beep `tray.rs`가 이미 전용 스레드 + 숨은 창 패턴을 갖고 있다 — 같은 구조 재사용). `GetClipboardSequenceNumber()`로 중복 확인 · `OpenClipboard` 실패는 **정상**(다른 앱이 잠금) → **짧은 백오프 재시도** |
| **macOS** | `NSPasteboard.general.changeCount` **폴링** | 이벤트가 없다. ★ **적응형 주기** — 포커스/입력이 있으면 200ms, 유휴면 1~2s로 늘린다(배터리). `changeCount`가 바뀔 때만 읽는다 |
| **Linux/X11** | `XFixesSelectSelectionInput(CLIPBOARD)` → `XFixesSelectionNotify` | 알림을 받으면 **소유자에게 `XConvertSelection`** 으로 실제 데이터를 요청. ⚠️ **창이 닫히면 데이터가 사라지므로 즉시 읽어 보관** |
| **Linux/Wayland** | `zwlr_data_control_manager_v1` (또는 `ext_data_control_manager_v1`) | ★ **GNOME(Mutter) 미지원** → 없으면 **"이 환경에서는 수집 불가"를 온보딩에서 명시**([R-4](02-roadmap.md#1-원칙--단계마다-쓸-수-있는-제품이어야-한다)). 조용한 빈 목록 금지 |

```rust
// nclip-core가 선언하고 nclip-plat이 구현하는 포트(의존성 역전)
pub trait ClipboardWatch {
    fn start(&mut self, on_change: Box<dyn Fn(ClipSnapshot) + Send>) -> Result<(), WatchError>;
    fn capability(&self) -> WatchCapability;   // ★ 미지원 사유를 정직하게 돌려준다
    fn pause(&mut self, on: bool);
}
```

### 3-2. `🆕` 다중 표현 읽기·쓰기 (FR-C-5·C-6 → [12](12-clipboard-formats.md))

**핵심 원칙(F-1)**: **해석하지 않고 이름째 전부 보관한다.**

| OS | 표현 열거 | 데이터 획득 |
|---|---|---|
| **Windows** | `EnumClipboardFormats(0)` 루프 + `GetClipboardFormatNameW`(등록 포맷 이름) | `GetClipboardData(fmt)` → `GlobalLock`/`GlobalSize` → 복사 → `GlobalUnlock` |
| **macOS** | `NSPasteboard.types` (UTI 배열) | `data(forType:)` |
| **Linux** | `TARGETS` 셀렉션 요청 → 타깃 목록 | 타깃별 `XConvertSelection` / Wayland는 offer의 `receive(mime, fd)` |

| 규칙 | 내용 |
|---|---|
| **F-2** | **평문 표현은 반드시 하나 만든다** — 없으면 HTML/RTF에서 파생. 폴백이 항상 있어야 한다 |
| **F-4** | 표현별 크기 상한(초안 8MB) 초과 시 **그 표현만 버리고** 나머지는 저장 |
| **쓰기** | 붙여넣기 모드에 따라 **올릴 표현을 고른다**([12 §5](12-clipboard-formats.md#5-붙여넣기-모드--네-가지)) — 원본 그대로 = 전부, 평문 = 하나만 |
| ⚠️ **HTML 정규화** | Windows `CF_HTML`은 **오프셋 헤더**(`StartHTML:`…)가 붙는다 → **저장은 순수 HTML로, 쓸 때 다시 씌운다** |

### 3-3. `🆕` 전역 단축키 (FR-U-1)

| OS | API | 주의 |
|---|---|---|
| **Windows** | `RegisterHotKey` → `WM_HOTKEY` | 숨은 창에서 수신 · 실패 = 이미 점유 → **충돌 표시** |
| **macOS** | `RegisterEventHotKey`(Carbon) | ★ **권한 불필요**(CGEventTap과 달리) — 이 이유로 우선 선택 |
| **Linux/X11** | `XGrabKey`(수정자 조합별로 여러 번) | NumLock/CapsLock 변형까지 등록해야 한다 |
| **Linux/Wayland** | ★ **표준 없음** — `xdg-desktop-portal` GlobalShortcuts 또는 **컴포지터 설정 안내** | 미지원 시 **트레이 클릭 경로로 유도** |

### 3-4. `⚠🆕` 직전 포커스 창 복원 + 키 주입 (FR-P-2) — **K-1 리스크**

> ★ **여기가 무너지면 자동 붙여넣기가 통째로 무너진다**([02 K-1](02-roadmap.md#7-리스크--일정을-실제로-흔들-것)).

**흐름**

```
① 단축키 수신
② ★ 직전 포그라운드 창/앱을 기억      ← 팝업을 띄우기 "전"
③ 팝업 표시(포커스 획득) · 사용자 선택
④ 팝업 숨김
⑤ ★ ②를 다시 활성화
⑥ 붙여넣기 키 주입(Ctrl+V / ⌘V)
```

| OS | ② 기억 | ⑤ 복원 | ⑥ 주입 |
|---|---|---|---|
| **Windows** | `GetForegroundWindow()` | `SetForegroundWindow` (+ **`AttachThreadInput` 트릭** — 포그라운드 제약 회피) | `SendInput`(Ctrl+V) |
| **macOS** | `NSWorkspace.frontmostApplication` | `activate(options:)` | `CGEventPost`(⌘V) — ★ **손쉬운 사용 권한 필수** |
| **Linux/X11** | `XGetInputFocus` | `XSetInputFocus` | `XTestFakeKeyEvent` |
| **Linux/Wayland** | ✕ | ✕ | ✕ **표준 없음** |

| 대비책 | 내용 |
|---|---|
| **정직한 강등** | 주입 불가 환경(권한 거부 · Wayland)에서는 **FR-P-1(클립보드에만 적재)로 내리고 안내** — 조용히 실패 금지 |
| 대안 검토 | Windows `WS_EX_NOACTIVATE` 창으로 **애초에 포커스를 뺏지 않는** 방식 → 복원 자체가 불필요. 단 키 입력 수신을 별도 처리해야 한다 → **스파이크에서 비교** |
| **첫 작업** | ★ 이 경로를 **가장 먼저 수직 슬라이스로 검증**한다(T-15) |

### 3-5. `🆕♻` 저장 (→ [06](06-storage-design.md))

```
data/
├─ index/ seg-NNNNNN.idx (append-only · AEAD)  +  manifest
├─ blob/  3f/3fa9c1…      (blob_id = H(암호문) · 2단계 디렉터리)
└─ keys                   (래핑된 마스터 키)
```

| 항목 | 구현 |
|---|---|
| **인덱스 레코드** | ≈270B(`item_id`·`blob_id`·타입·플래그·시각·크기·출처id·**미리보기 200B**) → **1만 항목 ≈ 2.7MB 메모리 상주** |
| **append 전용** | 레코드마다 `[길이][체크섬][본문]` — 꼬리가 깨지면 **마지막 레코드만 버린다** |
| **삭제** | 정책 만료 = **세그먼트 파일 통째 삭제** · 단건 = **묘비 레코드** + 컴팩션 |
| **원자성** | 새 `manifest`를 임시 파일에 쓰고 **원자적 rename** |
| **암호화** ♻ | beep `nbeep-store` 세그먼트 방식 이식 — AEAD · nonce = base+seq · AAD에 세그먼트 id. 키 계층 = 기기키 → KEK → 마스터 → 세그먼트 |
| **blob 중복 제거** | `blob_id`가 같으면 **파일을 안 만든다**. 참조 카운트로 회수 |

### 3-6. `♻🆕` 검색 (FR-F-1·F-2)

| 항목 | 구현 |
|---|---|
| **기본** | ★ **인덱스가 메모리에 있으므로 그냥 순회**한다 — 1만 건 부분 문자열 **1ms 미만**. **FTS 색인 불필요** |
| **대상** | `preview_text`(200B) 우선 → 필요 시 blob 복호 후 전문(백그라운드) |
| ★ **한글 조합 중** ♻ | IME **preedit(조합 중) 문자열을 쿼리에 즉시 반영**한다. Windows `WM_IME_COMPOSITION`(GCS_COMPSTR) · macOS `markedText` — beep `ime_gate.rs`(1,052 LOC) + `hangul.rs`(442) **이식** |
| **초성 검색**(선택) | `ㄱㄴㄷ`로 찾기 — 한국어 도구의 관용. 유니코드 한글 음절 분해(초성 인덱스 = `(c - 0xAC00) / 588`) |
| **정규식** | 메인창 전용(P1) · 잘못된 패턴은 **입력 중 오류 표시**하고 필터를 이전 상태로 유지 |
| **강조** | 일치 구간을 굵게/기울임/밑줄(`ui.highlight`) |

### 3-7. `🆕` 목록 렌더 — 3모드 + 가상화 (FR-U-14·U-10)

| 모드 | 행 높이 | 인덱싱 |
|---|---|---|
| **한 줄 / 간략** | **고정** | `first = scroll_y / row_h` — **O(1)** |
| ★ **일반** | **가변** | ★ **높이 캐시 + 누적합(prefix sum) 배열** → `first`를 **이진 탐색**으로 찾는다. 항목 추가는 **꼬리만 갱신** |

| 규칙 | 내용 |
|---|---|
| **V-1** | 세 모드 모두 **보이는 행만** 그린다 |
| **V-3** | 모드는 **렌더만** 바꾼다 — 선택·키 조작은 동일 |
| **썸네일** | 디코드는 ★ **`nclip-imgdec` 격리 프로세스**(♻ beep) · 결과는 **LRU 캐시**(크기 상한) |
| **텍스트** | ★ **가운데 생략**(앞뒤 남김) · 개행 `↵`·탭 `⇥` 기호로 치환([17 M-2·M-3](17-reference-ui-teardown.md#1-maccy-팝업-macos)) |

### 3-8. `🆕` 제한 리치텍스트 렌더러 (FR-U-16)

> ⚠️ *"리치텍스트를 그대로 보여준다"* 를 순진하게 만들면 **렌더러가 공격면**이 된다. 우리는 브라우저 엔진이 없다([DR-1](10-decision-record.md)).

| 규칙 | 내용 |
|---|---|
| **태그 화이트리스트** | `b i u s br p div span ul ol li table tr td th a font` — **그 외 전부 텍스트로 강등** |
| **속성 화이트리스트** | `color` · `font-weight` · `text-decoration` · `background-color` 정도 |
| ★ **금지** | 스크립트 · 이벤트 핸들러(`on*`) · **외부 리소스 로드**(`img src=http…`) · `<iframe>` · CSS 임의 실행 |
| **링크** | 파란 밑줄로 **표시만** 한다. 클릭은 **사용자 확인 후** 기본 브라우저로 |
| **RTF** | 1차는 **굵기·기울임·색만** 해석하고 나머지는 평문 폴백 |
| ★ **fail-closed** | 파싱 실패·상한 초과 = **평문 폴백**. 예외를 그리지 않는다 |
| **무해화** | 렌더 전에 RLO·제어문자 제거(♻ beep `SafeText`) |

### 3-9. `♻🆕` 트레이 (FR-U-2·U-13)

beep `tray.rs`(1,076 LOC · 3-OS)를 이식하고 **최근 항목 동적 갱신**만 추가한다.

| ★ **다음 1건만 무시** | 토글과 별개로 **1회성 스킵 플래그**([14 §2-2](14-settings-registry.md#2-2--다음-1건만-무시)) |

nexa-clip/                (bin) 조립 · 생명주기 · 창 라우팅 · 전역 단축키
├── nclip-core     도메인+포트  항목·표현 모델 · 정책 · i18n(Msg) · 포트 트레이트

├── nclip-ui       화면        ♻ settings 프레임워크 · hangul · typeahead · alert · prompt · about + S1~S8

## 7. 기능별 검증 방법

| 기능 | 검증 |
|---|---|
| 감시 | 텍스트·이미지·파일을 각 OS에서 복사 → **목록에 1건씩** · 같은 것 재복사 → **승격(중복 아님)** |
| ★ 원본 포맷 | **PPT 도형 → 우리 경유 → PPT** = **도형 그대로** · Excel 범위 = 수식 유지 |
| 평문 붙여넣기 | Word 복사 → `Shift+Enter` → 메모장에 서식 없음 |
| 자동 붙여넣기 | 임의 앱에서 단축키 → 선택 → **그 앱에 입력되고 포커스 유지** |
| 민감 차단 | 1Password/KeePass에서 복사 → **기록에 없음** |
| 성능 | 1만 항목에서 팝업 **≤100ms** · 검색 갱신 **≤16ms** |
| 예산 | 유휴 CPU **0%** · RSS **CI 게이트** |
| 3-OS 동일 | ★ **스크린샷으로 OS 구분 불가** |
| 정직한 강등 | Wayland/GNOME · mac 권한 거부에서 **안내가 뜨고 앱은 동작** |
